# MeasureSpark Project Instructions

## Stack

- Next.js 16 App Router
- React 19
- TypeScript 5
- Plain CSS with project tokens
- Vitest for unit tests
- Vercel deployment

## Product constraints

- English first; localization-ready routes and copy structure.
- No authentication, database, paid API, or server-side calculation in the first release.
- Display advertising is the monetization path, but ads must never displace the primary tool.
- `src/lib/tools.ts` is the source of truth for tool metadata and formulas.
- Read `PRODUCT.md` and `DESIGN.md` before UI changes.

## Validation

Run `pnpm validate`, `pnpm test`, and `pnpm build` before delivery.
