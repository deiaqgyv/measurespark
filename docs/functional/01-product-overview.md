# 产品总览 — MeasureSpark

| 字段 | 内容 |
|------|------|
| 域名 | https://measurespark.com |
| 类型 | 英文工具站 · 测量/家装计算器 |
| 技术栈 | Next.js 16 / React 19 / TypeScript / plain CSS / Vercel |
| 文档日期 | 2026-08-22 |

## 1. 一句话

为房主/租客/DIY 用户提供可立即使用的测量与材料估算工具；公式透明、本地运行。

## 2. 用户

英语优先（美国）；带着一个具体尺寸/材料问题而来。

## 3. 原则

1. 工具先于说明  
2. 假设用白话写在结果旁  
3. 元数据/关联工具单一真源（`tools.ts`）；**paint/flooring/tile 运行时公式在 `project-calculators.ts`**

## 4. 不做

- 账号/数据库/服务端计算  
- 打断主任务的广告（AdSlot 仅占位，**未挂载**）

## 5. 变现路径（规划）

展示广告（DESIGN/AGENTS）；Privacy 写明分析/广告尚未启用。
